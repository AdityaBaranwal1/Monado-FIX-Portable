## Method

- **Fps:**
  - RenoDX writes a telemetry line to `build/ReShade.log` every 30 s: `fps`, frame time percentiles, and
    `NR cost: gpu_ms` (GPU time spent on neural rendering), with an estimate of the fps without it.
  - The game's window title (`... (Recomp) - NN fps`) was read at fixed points while standing still, and after scripted
    walks (W 4 s, A 1.5 s, W 4 s).
- **On/off:** F6 was toggled with no camera input. Each state was held 35 s before reading.
- **VRAM:** `nvidia-smi --query-gpu=memory.used`.
- **Input:** a computer-use agent sent keys with `SendInput` and took the screenshots used to confirm the camera.

## GPU hangs (driver resets)

The System log has `nvlddmkm` event 153 at 01:26:38, 01:30:22, 01:35:50, 01:37:48, 01:40:06 and 01:46:20. Each matches
a `LiveKernelEvent 141` and an `xcde.exe` exit with `0xc0000409` in `ucrtbase.dll`, which is the runtime's FATAL. The
game log ends with `[vk] device fault: detail query failed` / `FATAL: sr failed: -4 (runtime/nvn/vulkan/exec.c:639)`.
The configuration matrix is in `docs/DLSS5.md` ("Known issue").
